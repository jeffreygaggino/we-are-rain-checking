# STRUCTURE — Go + Gin backend (greenfield)

Hand this to an agent at the **start of a new service**. It defines the stack, the bootstrap sequence, the layout, and
one complete vertical slice to copy. Build the slice first, verify it runs, then replace `Note` with the real domain.

**This file has one job and then it's finished:** get the skeleton standing. Once the slice runs and the gate is green,
`AGENTS-backend.md` takes over as the standing working agreement — how to behave, what to check, when to ask. Keep this
one as the reference for where code goes; where the two overlap on code, this file wins.

Fill in once: **module path** `<bitbucket.org/org/service-name>` · **DB schema** `<app>` · **image name**
`<org/service-name>`.

## Stack — use these, don't substitute

| concern | package | why it's fixed |
|---|---|---|
| HTTP | `github.com/gin-gonic/gin` | handler signature and grouping assumed throughout |
| CORS | `github.com/gin-contrib/cors` | |
| DB | `github.com/jmoiron/sqlx` + `github.com/lib/pq` | `sqlx.ExtContext` is what lets repos take a DB **or** a Tx |
| IDs | `github.com/google/uuid` | UUID primary keys everywhere, never serial ints |
| API docs | `github.com/swaggo/swag` + `gin-swagger` + `files` | annotations live on handlers; `swag init` runs in the build |
| HTTP/2 tuning | `golang.org/x/net/http2` | only if this service proxies streams (see Clients) |
| Migrations | `golang-migrate` file format | `000001_name.up.sql` / `.down.sql` |

Go 1.24+. Postgres. No ORM — hand-written SQL in repos.

## Bootstrap

```bash
mkdir <service-name> && cd <service-name>
go mod init <module-path>
go get github.com/gin-gonic/gin github.com/gin-contrib/cors github.com/jmoiron/sqlx \
       github.com/lib/pq github.com/google/uuid \
       github.com/swaggo/swag github.com/swaggo/gin-swagger github.com/swaggo/files
go install github.com/swaggo/swag/cmd/swag@latest
mkdir -p config db/migrations models repository services handlers routes permissions client cmd plans tmp
```

Then write, in this order — each step compiles before the next:

1. `config/config.go` → 2. `db/db.go` → 3. `db/migrations/000001_create_schema.up.sql` (+ `.down.sql`) →
4. `models/` (row, DTOs, errors, response envelope) → 5. `repository/` → 6. `services/` → 7. `permissions/` →
8. `handlers/helpers.go` then the handler → 9. `routes/routes.go` → 10. `main.go` → 11. `Makefile` + `Dockerfile` →
12. run the gate.

## Layout

```
main.go              composition root — wires everything, starts workers, runs the server
config/              one Config struct, loaded once at boot
db/                  connection + migrations/
models/              DTOs, DB rows, view models, sentinel errors, response envelopes
repository/          SQL only — one file per table/aggregate
services/            business logic, transactions, orchestration
handlers/            HTTP edge — one file per resource + helpers.go
routes/              one SetupRouter, all route registration
permissions/         permission sets per endpoint + the Require helper
client/              outbound clients for other services — one file each
docs/                generated by `swag init` — never hand-edit
cmd/<tool>/          auxiliary binaries (one-off scripts, backfills)
plans/               markdown plans, numbered NN-
```

File naming is `snake_case` and says its layer: `note_handler.go`, `note_service.go`, `note_repo.go`, `note.go`.

## The dependency rule

```
routes → handlers → services → repository → db
                 ↘ permissions        ↘ client
   everything may import models; models imports nothing internal
```

- **`handlers` never touch the database.** No `sqlx`, no SQL, no repo calls.
- **`services` never import `gin`.** They take `context.Context` plus the values they need, so a worker or a `cmd/`
  tool can call them.
- **`repository` never imports `services`** and holds no business rules — it reads and writes rows.
- **`models` is a leaf.** No framework imports.
- **Generated code is never hand-edited.** Regenerate and commit.

## 1. Migration — `db/migrations/000001_create_schema.up.sql`

```sql
CREATE SCHEMA IF NOT EXISTS app;

CREATE TABLE app.notes (
    id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
    title      text NOT NULL,
    body       text NOT NULL DEFAULT '',
    created_by uuid NOT NULL,
    created_at timestamptz NOT NULL DEFAULT NOW(),
    updated_at timestamptz NOT NULL DEFAULT NOW(),
    deleted_at timestamptz
);

CREATE INDEX notes_created_idx ON app.notes (created_at DESC) WHERE deleted_at IS NULL;
```

Every table gets `id uuid`, `created_at`, `updated_at`, `deleted_at`. **Soft delete is the default.** The `.down.sql`
drops what the `.up.sql` created, in reverse.

## 2. Config — `config/config.go`

```go
package config

import (
	"fmt"
	"log"
	"os"
)

type Config struct {
	Port       string
	DBHost     string
	DBPort     string
	DBName     string
	DBUser     string
	DBPassword string
	DBSchema   string
	PublicURL  string
	APIBasePath string
}

var cfg = &Config{}

func GetConfig() *Config { return cfg }

func Address() string { return fmt.Sprintf(":%s", cfg.Port) }

// LoadConfig reads the environment once at boot. Values with a sensible default get one;
// anything the service cannot run without is fatal here rather than a nil-ish surprise later.
func LoadConfig() {
	cfg.Port = envOr("PORT", "8080")
	cfg.DBHost = mustEnv("DB_HOST")
	cfg.DBPort = envOr("DB_PORT", "5432")
	cfg.DBName = mustEnv("DB_NAME")
	cfg.DBUser = mustEnv("DB_USER")
	cfg.DBPassword = mustEnv("DB_PASSWORD")
	cfg.DBSchema = envOr("DB_SCHEMA", "app")
	cfg.PublicURL = envOr("PUBLIC_URL", "localhost:"+cfg.Port)
	cfg.APIBasePath = envOr("API_BASE_PATH", "/api/v1")
}

func envOr(key, fallback string) string {
	if v := os.Getenv(key); v != "" {
		return v
	}
	return fallback
}

func mustEnv(key string) string {
	v := os.Getenv(key)
	if v == "" {
		log.Fatalf("config: %s is required", key)
	}
	return v
}
```

**Secrets never get a default.** A required value with no default and no validation is a runtime mystery; `mustEnv`
turns it into a startup error. Note that a value hardcoded in a compose/deploy file overrides the env file you're
reading.

`models/response.go` — the envelopes every handler uses:

```go
package models

import "math"

type ErrorResponse struct {
	Success bool   `json:"success" example:"false"`
	Code    int    `json:"code"    example:"400"`
	Message string `json:"message" example:"Failed response"`
}

type HttpResponse struct {
	Success bool        `json:"success"           example:"true"`
	Code    int         `json:"code,omitempty"    example:"200"`
	Message string      `json:"message"           example:"Successful response"`
	Data    interface{} `json:"data,omitempty"`
}

// PaginationResponse is the paged envelope returned as HttpResponse.Data.
// Mirror this shape field-for-field in the frontend's PaginationResponse<T>.
type PaginationResponse[T any] struct {
	FirstPage    bool `json:"firstPage"`
	LastPage     bool `json:"lastPage"`
	PageLength   int  `json:"pageLength"`
	TotalPages   int  `json:"totalPages"`
	TotalResults int  `json:"totalResults"`
	Data         []T  `json:"data"`
}

// NewPaginationResponse derives the flags from the page + total. `data` is never nil, so it
// encodes as [] rather than null.
func NewPaginationResponse[T any](data []T, page, pageLength, totalResults int) PaginationResponse[T] {
	if data == nil {
		data = []T{}
	}
	totalPages := 0
	if pageLength > 0 {
		totalPages = int(math.Ceil(float64(totalResults) / float64(pageLength)))
	}
	return PaginationResponse[T]{
		FirstPage:    page <= 1,
		LastPage:     page >= totalPages,
		PageLength:   pageLength,
		TotalPages:   totalPages,
		TotalResults: totalResults,
		Data:         data,
	}
}
```

**Every response goes through these two shapes.** No bare `c.JSON(200, someStruct)`.

## 5. Repository — `repository/note_repo.go`

```go
package repository

import (
	"context"
	"database/sql"
	"errors"
	"fmt"

	"github.com/google/uuid"
	"github.com/jmoiron/sqlx"

	"<module-path>/models"
)

// Stateless: the caller supplies the DB or a Tx, which is what makes a service-level
// transaction possible without changing a repo method.
type NoteRepo struct{}

func NewNoteRepo() *NoteRepo { return &NoteRepo{} }

func (r *NoteRepo) Insert(ctx context.Context, db sqlx.ExtContext, n *models.Note) error {
	const q = `
		INSERT INTO app.notes (title, body, created_by)
		VALUES (:title, :body, :created_by)
		RETURNING id, created_at, updated_at`

	rows, err := sqlx.NamedQueryContext(ctx, db, q, n)
	if err != nil {
		return fmt.Errorf("note_repo.Insert: %w", err)
	}
	defer rows.Close()

	if rows.Next() {
		if err := rows.Scan(&n.ID, &n.CreatedAt, &n.UpdatedAt); err != nil {
			return fmt.Errorf("note_repo.Insert scan: %w", err)
		}
	}
	return rows.Err()
}

func (r *NoteRepo) GetByID(ctx context.Context, db sqlx.ExtContext, id uuid.UUID) (*models.Note, error) {
	const q = `
		SELECT id, title, body, created_by, created_at, updated_at, deleted_at
		FROM app.notes
		WHERE id = $1 AND deleted_at IS NULL`

	var n models.Note
	if err := sqlx.GetContext(ctx, db, &n, q, id); err != nil {
		if errors.Is(err, sql.ErrNoRows) {
			return nil, models.ErrNoteNotFound
		}
		return nil, fmt.Errorf("note_repo.GetByID: %w", err)
	}
	return &n, nil
}

func (r *NoteRepo) List(ctx context.Context, db sqlx.ExtContext, limit, offset int) ([]models.Note, int, error) {
	const countQ = `SELECT COUNT(*) FROM app.notes WHERE deleted_at IS NULL`
	const q = `
		SELECT id, title, body, created_by, created_at, updated_at, deleted_at
		FROM app.notes
		WHERE deleted_at IS NULL
		ORDER BY created_at DESC
		LIMIT $1 OFFSET $2`

	var total int
	if err := sqlx.GetContext(ctx, db, &total, countQ); err != nil {
		return nil, 0, fmt.Errorf("note_repo.List count: %w", err)
	}

	var notes []models.Note
	if err := sqlx.SelectContext(ctx, db, &notes, q, limit, offset); err != nil {
		return nil, 0, fmt.Errorf("note_repo.List: %w", err)
	}
	return notes, total, nil
}

func (r *NoteRepo) Update(ctx context.Context, db sqlx.ExtContext, id uuid.UUID, title, body string) error {
	const q = `
		UPDATE app.notes
		SET title = $1, body = $2, updated_at = NOW()
		WHERE id = $3 AND deleted_at IS NULL`

	res, err := db.ExecContext(ctx, q, title, body, id)
	if err != nil {
		return fmt.Errorf("note_repo.Update: %w", err)
	}
	n, _ := res.RowsAffected()
	if n == 0 {
		return models.ErrNoteNotFound
	}
	return nil
}

func (r *NoteRepo) SoftDelete(ctx context.Context, db sqlx.ExtContext, id uuid.UUID) error {
	const q = `UPDATE app.notes SET deleted_at = NOW() WHERE id = $1 AND deleted_at IS NULL`

	res, err := db.ExecContext(ctx, q, id)
	if err != nil {
		return fmt.Errorf("note_repo.SoftDelete: %w", err)
	}
	n, _ := res.RowsAffected()
	if n == 0 {
		return models.ErrNoteNotFound
	}
	return nil
}
```

Repo rules, all visible above:

- SQL in a `const q`, **schema-qualified**.
- Every method takes `ctx` and `db sqlx.ExtContext` — never a stored handle.
- **Not-found is mapped here:** `sql.ErrNoRows` → sentinel, and zero `RowsAffected` → the same sentinel. Callers never
  inspect driver errors.
- Every error wrapped `repo_file.Method: %w`.
- A batch read takes a slice, returns early on empty, and uses `= ANY($1)` — so callers can avoid N+1 without a
  special case.

## 6. Service — `services/note_service.go`

```go
package services

import (
	"context"
	"fmt"

	"github.com/google/uuid"
	"github.com/jmoiron/sqlx"

	"<module-path>/models"
	"<module-path>/repository"
)

type NoteService struct {
	db       *sqlx.DB
	noteRepo *repository.NoteRepo
}

func NewNoteService(db *sqlx.DB, noteRepo *repository.NoteRepo) *NoteService {
	return &NoteService{db: db, noteRepo: noteRepo}
}

func (s *NoteService) Get(ctx context.Context, id uuid.UUID) (*models.Note, error) {
	return s.noteRepo.GetByID(ctx, s.db, id)
}

func (s *NoteService) List(ctx context.Context, page, pageLength int) ([]models.Note, int, error) {
	return s.noteRepo.List(ctx, s.db, pageLength, (page-1)*pageLength)
}

func (s *NoteService) Create(ctx context.Context, userID uuid.UUID, req models.CreateNoteRequest) (*models.Note, error) {
	note := models.Note{Title: req.Title, Body: req.Body, CreatedBy: userID}
	if err := s.noteRepo.Insert(ctx, s.db, &note); err != nil {
		return nil, fmt.Errorf("note_service.Create: %w", err)
	}
	return &note, nil
}

// Update shows the transaction shape: everything inside gets the Tx as its ExtContext,
// so either all of it lands or none of it does.
func (s *NoteService) Update(ctx context.Context, id uuid.UUID, req models.UpdateNoteRequest) (*models.Note, error) {
	tx, err := s.db.BeginTxx(ctx, nil)
	if err != nil {
		return nil, fmt.Errorf("note_service.Update begin: %w", err)
	}
	defer func() { _ = tx.Rollback() }()

	if err := s.noteRepo.Update(ctx, tx, id, req.Title, req.Body); err != nil {
		return nil, err
	}
	note, err := s.noteRepo.GetByID(ctx, tx, id)
	if err != nil {
		return nil, err
	}
	if err := tx.Commit(); err != nil {
		return nil, fmt.Errorf("note_service.Update commit: %w", err)
	}
	return note, nil
}

func (s *NoteService) Delete(ctx context.Context, id uuid.UUID) error {
	return s.noteRepo.SoftDelete(ctx, s.db, id)
}
```

**Sentinels pass through unwrapped or wrapped with `%w`** — never `%v`, or the handler's `errors.Is` stops matching and
every not-found becomes a 500.

## 7. Permissions — `permissions/`

`permissions/auth.go` — the contract handlers rely on:

```go
package permissions

import (
	"net/http"
	"slices"

	"github.com/gin-gonic/gin"
	"github.com/google/uuid"

	"<module-path>/models"
)

const authContextKey = "auth"

type AuthResult struct {
	UserID uuid.UUID
	Roles  []string
}

// ValidateFunc turns a request's credentials into an AuthResult. This is the seam where an
// org-wide auth service plugs in; main.go supplies the implementation.
type ValidateFunc func(*gin.Context) (*AuthResult, error)

// Middleware validates credentials once per request and stores the result.
func Middleware(validate ValidateFunc) gin.HandlerFunc {
	return func(c *gin.Context) {
		auth, err := validate(c)
		if err != nil || auth == nil {
			c.AbortWithStatusJSON(http.StatusUnauthorized, models.ErrorResponse{
				Success: false, Code: http.StatusUnauthorized, Message: "invalid or expired token",
			})
			return
		}
		c.Set(authContextKey, auth)
		c.Next()
	}
}

// Require reports whether the caller holds any of `allowed`. On failure the response is
// already written — the caller only needs to return.
func Require(c *gin.Context, allowed []string) (*AuthResult, bool) {
	value, exists := c.Get(authContextKey)
	auth, ok := value.(*AuthResult)
	if !exists || !ok {
		c.AbortWithStatusJSON(http.StatusUnauthorized, models.ErrorResponse{
			Success: false, Code: http.StatusUnauthorized, Message: "not authenticated",
		})
		return nil, false
	}

	for _, role := range auth.Roles {
		if slices.Contains(allowed, role) {
			return auth, true
		}
	}

	c.AbortWithStatusJSON(http.StatusForbidden, models.ErrorResponse{
		Success: false, Code: http.StatusForbidden, Message: "insufficient permissions",
	})
	return nil, false
}
```

`permissions/permissions.go` — one var per endpoint, grouped by resource:

```go
package permissions

var (
	// ── Notes ─────────────────────────────────────────────────────────────────
	GetNotes   = []string{"notes/Notes-View", "notes/Notes-Add+Update", "notes/Notes-Delete"}
	GetNote    = []string{"notes/Notes-View", "notes/Notes-Add+Update", "notes/Notes-Delete"}
	PostNote   = []string{"notes/Notes-Add+Update", "notes/Notes-Delete"}
	PatchNote  = []string{"notes/Notes-Add+Update", "notes/Notes-Delete"}
	DeleteNote = []string{"notes/Notes-Delete"}
)
```

- **Never inline a role string in a handler** — this file is the readable answer to "who can do what".
- **Never derive a permission from a display label.** Rename the label upstream and the lookup falls through to `""`,
  which reads as "denied" everywhere with nothing to trace. Key off IDs — seeded, or loaded at startup with a
  fail-fast check.
- **Never add a bypass for local development.** If local auth is broken, the token flow is the bug.

## 8. Handlers — `handlers/`

`handlers/helpers.go` — the three primitives every handler uses:

```go
package handlers

import (
	"net/http"

	"github.com/gin-gonic/gin"
	"github.com/google/uuid"

	"<module-path>/models"
)

// parseUUID parses a named path parameter, writing a 400 on failure.
func parseUUID(c *gin.Context, param string) (uuid.UUID, bool) {
	id, err := uuid.Parse(c.Param(param))
	if err != nil {
		errorResponse(c, http.StatusBadRequest, "invalid UUID for parameter: "+param)
		return uuid.UUID{}, false
	}
	return id, true
}

func errorResponse(c *gin.Context, status int, msg string) {
	c.JSON(status, models.ErrorResponse{Success: false, Code: status, Message: msg})
}

func successResponse(c *gin.Context, status int, msg string, data interface{}) {
	c.JSON(status, models.HttpResponse{Success: true, Code: status, Message: msg, Data: data})
}
```

`handlers/note_handler.go` — **every handler body follows the same seven steps**, so two handlers can be diffed by eye:

```go
package handlers

import (
	"errors"
	"net/http"
	"strconv"

	"github.com/gin-gonic/gin"

	"<module-path>/models"
	"<module-path>/permissions"
	"<module-path>/services"
)

type NoteHandler struct {
	noteService *services.NoteService
}

func NewNoteHandler(noteService *services.NoteService) *NoteHandler {
	return &NoteHandler{noteService: noteService}
}

// PostNote creates a note.
//
//	@Summary	Create note
//	@Tags		notes
//	@Accept		json
//	@Produce	json
//	@Param		body	body		models.CreateNoteRequest	true	"Note payload"
//	@Success	201		{object}	models.HttpResponse{data=models.Note}
//	@Failure	400		{object}	models.ErrorResponse
//	@Router		/notes [post]
func (h *NoteHandler) PostNote(c *gin.Context) {
	// 1. Permission
	auth, ok := permissions.Require(c, permissions.PostNote)
	if !ok {
		return
	}

	// 2. Bind the body
	var req models.CreateNoteRequest
	if err := c.ShouldBindJSON(&req); err != nil {
		errorResponse(c, http.StatusBadRequest, err.Error())
		return
	}

	// 3. Call the service
	note, err := h.noteService.Create(c.Request.Context(), auth.UserID, req)
	if err != nil {
		errorResponse(c, http.StatusInternalServerError, "internal error")
		return
	}

	// 4. Respond through the envelope
	successResponse(c, http.StatusCreated, "note created", note)
}

// GetNotes returns a page of notes.
//
//	@Summary	List notes
//	@Tags		notes
//	@Produce	json
//	@Param		page		query		int	false	"1-based page number"
//	@Param		pageLength	query		int	false	"rows per page"
//	@Success	200			{object}	models.HttpResponse{data=models.PaginationResponse[models.Note]}
//	@Router		/notes [get]
func (h *NoteHandler) GetNotes(c *gin.Context) {
	if _, ok := permissions.Require(c, permissions.GetNotes); !ok {
		return
	}

	page := queryInt(c, "page", 1)
	pageLength := queryInt(c, "pageLength", 25)

	notes, total, err := h.noteService.List(c.Request.Context(), page, pageLength)
	if err != nil {
		errorResponse(c, http.StatusInternalServerError, "internal error")
		return
	}

	successResponse(c, http.StatusOK, "notes retrieved",
		models.NewPaginationResponse(notes, page, pageLength, total))
}

// PatchNote updates a note the caller owns.
//
//	@Summary	Update note
//	@Tags		notes
//	@Accept		json
//	@Produce	json
//	@Param		id		path		string						true	"Note UUID"
//	@Param		body	body		models.UpdateNoteRequest	true	"New values"
//	@Success	200		{object}	models.HttpResponse{data=models.Note}
//	@Failure	404		{object}	models.ErrorResponse
//	@Router		/notes/{id} [patch]
func (h *NoteHandler) PatchNote(c *gin.Context) {
	// 1. Permission
	auth, ok := permissions.Require(c, permissions.PatchNote)
	if !ok {
		return
	}

	// 2. Parse path params
	id, ok := parseUUID(c, "id")
	if !ok {
		return
	}

	// 3. Fetch + check the precondition that needs the record
	existing, err := h.noteService.Get(c.Request.Context(), id)
	if err != nil {
		respondServiceError(c, err)
		return
	}
	if existing.CreatedBy != auth.UserID { // drop this block where ownership doesn't apply
		errorResponse(c, http.StatusForbidden, "cannot edit another user's note")
		return
	}

	// 4. Bind the body
	var req models.UpdateNoteRequest
	if err := c.ShouldBindJSON(&req); err != nil {
		errorResponse(c, http.StatusBadRequest, err.Error())
		return
	}

	// 5. Call the service
	note, err := h.noteService.Update(c.Request.Context(), id, req)
	if err != nil {
		respondServiceError(c, err)
		return
	}

	// 6. Respond
	successResponse(c, http.StatusOK, "note updated", note)
}

// respondServiceError maps sentinels to status codes. Everything unmatched is a 500 with a
// generic message — never echo an internal error to the client.
func respondServiceError(c *gin.Context, err error) {
	switch {
	case errors.Is(err, models.ErrNoteNotFound):
		errorResponse(c, http.StatusNotFound, err.Error())
	default:
		errorResponse(c, http.StatusInternalServerError, "internal error")
	}
}

func queryInt(c *gin.Context, key string, fallback int) int {
	value, err := strconv.Atoi(c.Query(key))
	if err != nil || value < 1 {
		return fallback
	}
	return value
}
```

The seven steps in order: **permission → path params → body bind → record-dependent checks → service call → error
mapping → envelope response.** Steps that don't apply are omitted, never reordered.

## 9. Routes — `routes/routes.go`

```go
package routes

import (
	"github.com/gin-contrib/cors"
	"github.com/gin-gonic/gin"

	"<module-path>/handlers"
	"<module-path>/permissions"
)

func corsConfig(origins []string) cors.Config {
	config := cors.DefaultConfig()
	config.AllowOrigins = origins
	config.AllowCredentials = true
	config.AllowHeaders = []string{"Content-Type", "Content-Length", "Accept-Encoding", "X-CSRF-Token",
		"Authorization", "accept", "origin", "Cache-Control", "X-Requested-With"}
	config.AllowMethods = []string{"PUT", "POST", "GET", "DELETE", "OPTIONS", "PATCH"}
	return config
}

func SetupRouter(noteHandler *handlers.NoteHandler, validateAuth permissions.ValidateFunc) *gin.Engine {
	router := gin.Default()
	router.Use(cors.New(corsConfig([]string{"https://app.example.com"})))
	router.Use(permissions.Middleware(validateAuth))

	v1 := router.Group("/api/v1")
	{
		// Notes
		notes := v1.Group("/notes")
		{
			notes.POST("", noteHandler.PostNote)
			notes.GET("", noteHandler.GetNotes)
			notes.GET("/:id", noteHandler.GetNote)
			notes.PATCH("/:id", noteHandler.PatchNote)
			notes.DELETE("/:id", noteHandler.DeleteNote)
		}
	}

	return router
}
```

- One group per resource, each headed by a one-line comment.
- **Nest only where the child is owned by the parent** (`/notes/:id/comments`). A resource addressable on its own is
  registered flat, or callers have to carry an ID they don't have.
- **Routes carry no logic** — no inline closures, no permission checks here.

## 10. Composition root — `main.go`

```go
package main

import (
	"os"

	"<module-path>/config"
	"<module-path>/db"
	"<module-path>/docs"
	"<module-path>/handlers"
	"<module-path>/repository"
	"<module-path>/routes"
	"<module-path>/services"

	swaggerFiles "github.com/swaggo/files"
	ginSwagger "github.com/swaggo/gin-swagger"
)

//	@title			<Service> API
//	@version		0.1
//	@description	<one line>
//	@BasePath		/api/v1
func main() {
	config.LoadConfig()
	db.ConnectDatabase(config.GetConfig())

	docs.SwaggerInfo.Host = config.GetConfig().PublicURL
	docs.SwaggerInfo.BasePath = config.GetConfig().APIBasePath

	// Repositories
	noteRepo := repository.NewNoteRepo()

	// Clients
	// (outbound service clients go here)

	// Services
	noteService := services.NewNoteService(db.DB, noteRepo)

	// Handlers
	noteHandler := handlers.NewNoteHandler(noteService)

	// Background workers — started here so their lifetime is visible in one file
	// uploadQueueService.Start()

	router := routes.SetupRouter(noteHandler, validateAuth())
	router.GET("/docs/*any", ginSwagger.WrapHandler(swaggerFiles.Handler))

	if tlsCert, tlsKey := os.Getenv("TLS_CERT"), os.Getenv("TLS_KEY"); tlsCert != "" {

	} else {
		_ = router.Run(config.Address())
	}

```

`validateAuth()` returns the `permissions.ValidateFunc` for this service — the one place that knows how a token
becomes a user and a role list (a call to the org's auth service, a JWT parse, a session lookup). It lives in `main.go`
or its own small package, never inside a handler.

One wiring order, always: **repositories → clients → services → handlers → workers → router → serve.** Constructors
take their dependencies explicitly; no package-level singletons beyond config and the DB handle.

# Clients — `client/`

One file per upstream service. Two client shapes, and the difference is not cosmetic:

```go
// newApiHttpClient is for small JSON exchanges — one timeout covers the whole request.
func newApiHttpClient(timeout time.Duration) *http.Client {
	return &http.Client{Timeout: timeout}
}
```

```go
// newStreamingHttpClient is for proxying a large body straight through to the caller.
// http.Client.Timeout covers READING THE BODY, so a whole-request timeout truncates a large
// stream mid-flight. Bound the phases instead.
func newStreamingHttpClient() *http.Client {
	// Clone, never mutate: DefaultTransport is process-global.
	transport := http.DefaultTransport.(*http.Transport).Clone()
	transport.ResponseHeaderTimeout = 20 * time.Second // time to FIRST BYTE
	transport.IdleConnTimeout = 30 * time.Second       // don't reuse a connection a NAT may have dropped

	// h2 keepalive is the only one of these that catches a connection dying WHILE in use.
	if h2Transport, err := http2.ConfigureTransports(transport); err == nil {
		h2Transport.ReadIdleTimeout = 30 * time.Second
		h2Transport.PingTimeout = 5 * time.Second
	}

	return &http.Client{Transport: transport}
}
```

- **Never use the zero-value client.** It has no timeout at all — that's minute-long stalls, not a tidy leak.
- **Propagate the upstream status and message.** Flattening every non-2xx into a gateway error turns their
  `400 unrecognised path` into your `502`, and sends the next debugger to the wrong service.
- **Forward the headers the contract depends on** when proxying — range, conditional, content type/length. Dropping
  conditional headers makes `304`s impossible and forces a full re-download every time.
- **Absent cache headers are not neutral:** with no `Cache-Control`, caches invent freshness from the last-modified
  date. `no-cache` means "revalidate before reuse", not "don't store".
- Keep each upstream's response shape in **that client's file** — don't leak a third party's envelope into `models/`.

# Makefile

Every environment's values live as variables at the **top** of the file, never inline in a recipe — that's what makes
"what does dev actually point at?" answerable by reading ten lines.

```makefile
IMAGE_NAME  = <org>/<service-name>
TAG_DEV     = latestdev
TAG_PROD    = latest
DATE       := $(shell date +%Y%m%d)
PLATFORM    = linux/amd64
REMOTE_HOST = <user>@<deploy-host>

DB_NAME_DEV      = <db>
PUBLIC_URL_DEV   = <service-dev.example.com>
API_BASE_PATH_DEV = /be/api/v1

DB_NAME_PROD      = <db>
PUBLIC_URL_PROD   = <service.example.com>
API_BASE_PATH_PROD = /be/api/v1

# ── Local development ─────────────────────────────────────────────────────────

.PHONY: tidy build test local
tidy:  ; @go mod tidy
build: ; @swag init && go build -o ./tmp/<service-name> .
test:  ; @go test -v ./... -cover
local: ; docker compose -f docker-compose.local.yml up --build

# ── Build stages ──────────────────────────────────────────────────────────────

.PHONY: dev-build
dev-build:
	@docker build \
		--platform ${PLATFORM} --no-cache \
		--build-arg DB_NAME=${DB_NAME_DEV} \
		--build-arg PUBLIC_URL=${PUBLIC_URL_DEV} \
		--build-arg API_BASE_PATH=${API_BASE_PATH_DEV} \
		-t ${IMAGE_NAME}:DEV$(DATE) \
		-t ${IMAGE_NAME}:${TAG_DEV} .

# ── Push stages ───────────────────────────────────────────────────────────────

.PHONY: dev-push
dev-push:
	@docker push ${IMAGE_NAME}:DEV$(DATE)
	@docker push ${IMAGE_NAME}:${TAG_DEV}

# ── Deploy (build + push + reload) ────────────────────────────────────────────

.PHONY: dev
dev:
	@$(MAKE) dev-build
	@$(MAKE) dev-push
	@ssh ${REMOTE_HOST} './reload-<service-name>-dev'

# ── CI (build + push only, no SSH reload) ─────────────────────────────────────

.PHONY: dev-ci
dev-ci:
	@$(MAKE) dev-build
	@$(MAKE) dev-push
```

Mirror the whole `*-build` / `*-push` / deploy / `*-ci` set for prod.

## Which targets an agent may run

**`make dev` is not a dev server — it is a deploy.** It builds, pushes, and SSHes to the host to reload the running
service. Same for `make prod`. The naming collides with the convention in most other repos, so state it here rather
than trusting anyone to check.

| target | what it does | agent may run |
|---|---|---|
| `tidy`, `build`, `test` | local, no side effects beyond the working tree | yes |
| `local` | runs the stack locally via compose | yes |
| `dev-build`, `prod-build` | builds a docker image locally | ask first — slow, and tags an image |
| `dev-push`, `prod-push` | **publishes an image to the registry** | no — outward-facing |
| `dev-ci`, `prod-ci` | build + push, no reload | no — outward-facing, CI's job |
| `dev`, `prod` | **build + push + reload a live environment** | never without an explicit instruction |

# Checklists

**New endpoint, end to end:**

1. `models/` — request DTO, response shape, any new sentinel in `errors.go`
2. `repository/` — SQL method(s) taking `ctx, db sqlx.ExtContext`, not-found mapped to the sentinel
3. `services/` — business logic, transaction boundary, `%w` wrapping
4. `permissions/` — the role set, in the right resource group
5. `handlers/` — the seven-step body in the resource's file, plus swagger annotations
6. `routes/` — one line in the right group
7. `main.go` — only if a new repo/service/handler type appeared
8. Run the gate, report, stop

**New upstream dependency:**

1. `client/<service>_client.go` with an explicit timeout and typed methods
2. `config/` entry — URL may default per environment, key never does
3. Wire it in `main.go` (clients block) and pass it to the service that needs it
4. Record in `plans/` what makes two records the same across the boundary (the dedup/idempotency key — prefer a
   content hash over a filename) and which side owns the resource

# Gate — run before calling anything done

```bash
gofmt -l .          # must print nothing
go vet ./...
swag init           # regenerate docs when handler annotations changed
go build ./...
go test ./... -cover
```

Report the output. Don't commit — that's the human's call.

# Testing

Keep decisions in functions that take values, not methods that query — validation, mapping, derivation. That's the
surface worth unit-testing and it needs no database. Where a service itself must be exercised, it's the layer that
takes an `sqlx.ExtContext`: inject a transaction and roll it back.
